# E-Commerce Sales Analysis

Exploratory data analysis and modeling on e-commerce sales data.

## Project Overview
This repository contains an exploratory data analysis and visualization workflow for an e-commerce sales dataset.  
The original work was developed in a Jupyter Notebook (`e commerce sales (1).ipynb`).  
This project includes:
- Data loading and cleaning  
- Exploratory data analysis (EDA)  
- Feature engineering and preprocessing  
- Visualization and insights generation  
- (Optional) modeling and evaluation  

---

## Files
- `e commerce sales (1).ipynb` — Original Jupyter Notebook  
- `e_commerce_sales.py` — Python script version of the notebook  
- `requirements.txt` — List of dependencies  
- `README.md` — Project documentation (this file)
